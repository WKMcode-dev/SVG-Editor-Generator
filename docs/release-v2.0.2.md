# SVG Editor Generator 2.0.2

- Elipses começam com quatro pontos suaves nos eixos, sem conversão para 96 pontos ao editar.
- O círculo inicial mantém arcos exatos; mover os pontos preserva curvas suaves.
- Formas dos presets começam com proporções equilibradas, círculos e linhas horizontais.
- Shift+clique em outra forma sai da edição de pontos e permite seleção múltipla de objetos.
- Caixa de seleção inclui formas tocadas; camadas ocultas/bloqueadas seguem protegidas.
- Exportação, histórico e operações booleanas preservados; booleanas ainda usam aproximação poligonal.
